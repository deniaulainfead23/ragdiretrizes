# dados_derivados

Resultados do RAG. Pode ser apagado e refeito.

- `respostas/` — uma rodada por arquivo `.json`: pergunta, resposta e trechos citados (passo 4).
- `validacao/` — para cada rodada, um `.json` detalhado e um `.csv` resumo com o veredito de cada resposta (passo 5).
- `tfidf/` — uma pasta por comparação TF-IDF (opção 8), com CSVs, gráfico e um `LEIA-ME.md` de interpretação.
