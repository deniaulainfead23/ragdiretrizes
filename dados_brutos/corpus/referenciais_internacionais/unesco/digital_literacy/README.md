## Papel metodológico

- Não é tratado como país ou currículo nacional.
- Não substitui o framework `UNESCO_GCED_2015`.
- Atua como referência para competências e letramento digital.
- É usado como estrutura de classificação de evidências, não como ranking,
  índice de qualidade curricular ou medida de implementação.
- Ausência de evidência recuperada não implica ausência conceitual no currículo.
