# dados_brutos/referencias

Fontes de comparação para a análise TF-IDF (opção 8 do menu). Você decide o que entra aqui.

- **Lista de termos** — `.txt` ou `.csv`. Uma linha por termo, ou `categoria;termo`.
  Veja `exemplo_dlgf_2018.csv` (áreas e palavras-chave do Digital Literacy Global Framework).
- **Documento de referência** — `.pdf`, `.docx`, `.txt`, `.md` ou `.html`. Por exemplo, o PDF de um framework.

Um `.txt` pode servir aos dois usos; o menu pergunta qual é o caso.

Guia completo: `COMO_COMPARAR_TFIDF.md`, na raiz do projeto.
