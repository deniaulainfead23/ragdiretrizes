# dados_brutos

Documentos originais, exatamente como foram obtidos. Nada aqui é alterado pelo pipeline.

Coloque os arquivos em `dados_brutos/corpus/`, em qualquer ordem e em qualquer
estrutura de pastas. Formatos lidos: `.pdf`, `.docx`, `.txt`, `.md`, `.html`.

Se você usar subpastas (por exemplo, uma por país), o nome da primeira pasta vira
um filtro opcional na hora de perguntar. Não é obrigatório.

Os documentos não são versionados no git (veja `.gitignore`).
